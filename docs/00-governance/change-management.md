# Change Management

- Owner: Change Advisory Board
- Status: `Draft`
- Review: `2027-02-13`

## Rules

- MUST create a change record for scope, data, API, security, SLO or production changes.
- MUST record objective, scope, affected systems, risk, rollout, verification, rollback, approver and execution time.
- MUST obtain required approval before execution.
- MUST record evidence after execution.
