# Handoff Gate

- MUST update `handoff.md`.
- MUST record current phase.
- MUST record last completed.
- MUST record next action.
- MUST record decisions, changed files, validation and blockers.
- MUST update `verification.md` and `evaluation.md`.

## PASS

Task can resume from `Next action` without inference.

## FAIL

Do not close task or transfer state.
