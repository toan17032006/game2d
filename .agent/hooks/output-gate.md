# Output Gate

- MUST compare output with every acceptance criterion.
- MUST verify format, completeness, correctness and scope.
- MUST remove placeholder, TODO and unsupported claim.
- MUST separate `VERIFIED`, `DRY-RUN` and `UNVERIFIED`.
- MUST record limitations.

## PASS

Every acceptance criterion has PASS evidence.

## FAIL

Do not report `COMPLETED`.
