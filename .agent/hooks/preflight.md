# Preflight Hook

- MUST read `/AGENTS.md`.
- MUST identify Task ID.
- MUST read existing `handoff.md`.
- MUST identify source-of-truth paths.
- MUST classify input as `DIRECT`, `CLARIFYING` or `AWAITING_APPROVAL`.
- MUST record missing input.

## PASS

Task ID, scope, source paths and required input are present.

## FAIL

Stop. Record missing input in `handoff.md`.
