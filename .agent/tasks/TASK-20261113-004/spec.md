# Specification

## Inputs

- Task ID.
- Task workspace.
- Repository root.

## Constraints

- PowerShell.
- Không sửa code sản phẩm.
- Không bỏ qua lỗi bắt buộc.

## Output contract

- Exit `0`: PASS.
- Exit non-zero: FAIL.
- Output: file, rule, result.
