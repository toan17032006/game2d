# Specification

## Inputs

- Markdown hiện có trong repository.
- Chuẩn điều phối tại `/docs/00-governance/agent-execution-standard.md`.

## Confirmed facts

- Agent phải đọc Markdown theo mặc định.
- Agent chỉ sửa Markdown khi User yêu cầu trực tiếp.
- Tài liệu cần dùng điều lệnh ngắn.

## Constraints

- Không dùng diễn giải dài.
- Không tạo nội dung ngoài scope.
- Không bỏ References.

## Output contract

Markdown dùng heading ngắn, bảng khi cần, điều lệnh bắt buộc và path root-relative.
