# Contributing

## Rules

- MUST đọc `/AGENTS.md`.
- MUST tạo Task ID cho task cần thực hiện.
- MUST cập nhật task workspace tại `/.agent/tasks/<TASK-ID>/`.
- MUST tạo ADR cho thay đổi kiến trúc.
- MUST cập nhật requirements và verification cho thay đổi hành vi.
- MUST chạy validation trước khi báo hoàn tất.
